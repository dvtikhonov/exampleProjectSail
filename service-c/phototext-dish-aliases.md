# PhotoText: словарь соответствий имён блюд


Общий словарь для `/phototext-order` и `/phototext-schedule`.  
Сырое имя с бланка/графика → **каноническое** `dishes[].name` из каталога выбранного ресторана.

## Правила применения

1. Читать этот файл **до** сопоставления OCR с каталогом.
2. Сначала нормализовать строку (вес, цена, пробелы), затем проверить словарь (без учёта регистра, кавычек, ё/е).
3. Если есть запись и канон **есть** в каталоге текущего ресторана (для schedule — ещё и в выбранных категориях) — брать канон из словаря.
4. Если канона в каталоге нет — словарь **не** применять, строку не угадывать (issue / не слать).
5. Если записи нет — обычные правила «Вариации имён» из команды.
6. Новые пары добавлять сюда после подтверждения пользователем или однозначного матча в каталоге. Не дублировать пары, которые уже закрываются перестановкой слов.
